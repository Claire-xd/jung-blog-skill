# jung-blog-skill

用荣格（Carl Gustav Jung）心理学撰写**英文情感/关系心理博客**的 Codex Skill——按 SEO 博客规范直接产出文章。

- 定位：情感专家视角——把荣格的阿尼玛/阿尼姆斯、阴影、投射、个体化、情结翻译成情感/关系文章的心理深度
- 内核：6 个心智模型 + 8 条决策启发式 + 完整表达 DNA（源自 6 维度深度调研，70+ 来源，一手占比约 60%）
- 博客引擎：标题引擎（数字+主题+场景+情感）→ 提问开场 → 两级锚点目录 → 模块化正文 → Conclusion → SEO 元信息 → 图片规划（16:9 封面 + 4:3 内容图）
- 附带：荣格概念 × 情感场景映射表（投射/阴影/阿尼玛/个体化…→ 具体关系现象）+ 示例文章（examples/）

## 安装

- Codex：把本目录复制到 `~/.codex/skills/jung-blog-skill/`
- 其他兼容 runtime（Claude Code、Cursor 等）：复制到对应 skills 目录
- 或使用通用安装器：`npx skills add <owner>/jung-blog-skill`

## 使用

- 「写一篇英文情感心理博客」
- 「帮我写一篇关于'为什么总爱上同一类人'的英文文章（按博客规范）」
- 「给几个情感+心理选题」
